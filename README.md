# nikhilgeorge.com

Personal site of Nikhil George, served by GitHub Pages at [www.nikhilgeorge.com](https://www.nikhilgeorge.com).

Plain static HTML/CSS/JS, with no build step or framework.

- `index.html`: all content
- `assets/css/site.css`: styles (light/dark tokens at the top)
- `assets/js/site.js`: theme toggle and footer year
- `assets/images/profile.jpeg`: profile photo

Preview locally with `python3 -m http.server` and open http://localhost:8000.
